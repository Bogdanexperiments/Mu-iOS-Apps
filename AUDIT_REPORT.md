
## Автоматические тесты Liquid Glass и логотипа

Добавлен `Tests/LiquidGlassAndLogoTests.swift`. Тесты проверяют сохранение заданного радиуса `LiquidGlassModifier`, построение convenience API `.liquidGlass(cornerRadius:)`, размеры `FoundationLogoView` по умолчанию и при пользовательском значении, а также успешное построение SwiftUI view-типов. Новый файл подключён к `SCPFoundationTests` target вместе с существующими `SCPStoreTests`.
